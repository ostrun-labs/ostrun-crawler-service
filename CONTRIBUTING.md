# Contributing to ostrun-crawler-service

This service follows the contribution rules of the main [Ostrun repository](https://github.com/ostrun-labs/ostrun/blob/main/CONTRIBUTING.md). Read them first, in particular the [pull request process](https://github.com/ostrun-labs/ostrun/blob/main/CONTRIBUTING.md#pull-request-process).

## Versioning

Tag format, semver rules and the release flow are defined once, in Ostrun's [Versioning a service](https://github.com/ostrun-labs/ostrun/blob/main/CONTRIBUTING.md#versioning-a-service). They are not repeated here, so that they can't drift. The `version` to bump is the one in [`ostrun.manifest.json`](./ostrun.manifest.json).
